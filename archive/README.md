# Archiwum

Pliki zachowane wyłącznie jako referencja — **nie są używane** przez `npm run dev` / `npm run build`.

| Ścieżka | Opis |
|---------|------|
| `Skarb kibica - wyjsciowa.html` | Monolityczna wersja aplikacji sprzed refaktoryzacji Vite |
| `migration/` | Jednorazowe skrypty ekstrakcji kodu z HTML do `src/` |

Można bezpiecznie usunąć cały folder `archive/`, jeśli nie potrzebujesz historii.
