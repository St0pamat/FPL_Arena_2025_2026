# Logotypy portalu (splash screen)

Pliki generowane automatycznie przez `scripts/sync-public.mjs` z folderu `logo/`:

| Źródło | Cel |
|--------|-----|
| `logo/FPL Arena.png` | `fpl-arena-logo.png` |
| `logo/Na Minusie.png` | `na-minusie-logo.png` |

Uruchom `npm run dev` lub `npm run build` — sync skopiuje pliki przed startem.
